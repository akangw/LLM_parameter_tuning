本文件保留用于兼容旧链接。当前项目已独立于 `vllmTKB0706`，权威文档统一放在项目根目录：

- `README.md`：项目概览、当前状态与快速入口；
- `docs/ARCHITECTURE.md`：本地控制面、远端执行面和完整自动化链路；
- `docs/DEPENDENCIES.md`：依赖、版本和允许保留的 `liuxin-workspace` 只读依赖；

- `docs/OPERATIONS.md`：启动、恢复、停止和故障处理；
- `docs/HANDOFF.md`：交接清单。

人工和自动 Search Limits 都在新 Session 创建时现场编译；唯一在线权威机器产物是该 Session 的 `00_search_space/`。当前人工路径为 Active 15、Reserve 5、Fixed 5、Rejected 1；自动路径为 102 Tunable（Active 22、Reserve 80）和 40 Fixed。
